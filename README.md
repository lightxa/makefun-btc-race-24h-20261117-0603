Build a bot that trades Coinbase Wrapped BTC (cbBTC) on 1-minute on-chain prices with $1,000 of paper money for the highest net PnL over 24 hours; $250 goes to the 10 highest net PnLs. The bot is a range-low mean-reversion trader: it buys only near the 200-bar trailing low on an uptick, full size, long only, and exits at +1.2% take-profit, -1.2% stop-loss, or a 480-bar time exit.

## Run it

```sh
python3 -P -s main.py
```
